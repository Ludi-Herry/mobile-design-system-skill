# 03 移动端导航架构与手势系统 (Navigation & Gestures)

导航是用户在微小屏幕上理解信息空间位置的地图。移动端导航必须将“顶级入口、次级分支、深度下钻与临时支线”严谨分层。

---

## 一、移动端四大经典导航模式

```text
┌─────────────────────────────────────────────────────────────┐
│ 1. 标签栏导航 (TabBar / BottomNav)                          │
│    - 3–5 个一级核心业务空间，常驻屏幕底部自然舒适区          │
├─────────────────────────────────────────────────────────────┤
│ 2. 顶部切换栏 (Top Segmented / Scrollable Tabs)             │
│    - 单一模块内的平级业务视角切换（平铺 2-4 项或横向可滑）   │
├─────────────────────────────────────────────────────────────┤
│ 3. 栈式层级下钻 (Hierarchical Navigation Stack)             │
│    - 从列表点击条目，新页面从右向左滑入 (Push)，左滑退回     │
├─────────────────────────────────────────────────────────────┤
│ 4. 浮动半屏抽屉 (Modal Bottom Sheet)                        │
│    - 临时调起支线任务（如筛选面板、分享面板、多属性规格选择） │
└─────────────────────────────────────────────────────────────┘
```

### 1. 底部标签栏 (TabBar) 硬门禁
- **槽位数量**：严格限定为 **3 到 5 个**。少于 3 个会浪费横向空间，多于 5 个会导致单项触控热区低于 44pt，极易发生手指误触。
- **图标与文字组合**：优先采用“图标上、文字下”或“纯图标配微文字提示”的组合。文字严禁超出 4 个汉字。
- **徽标计数 (Badge) 与小红点三档克制**：
  - **右上角锚定与向左单向膨胀**：Badge 锚点严格定位在图标右上角（`top-0 right-0 -translate-y-1/3 translate-x-1/3`）；当未读数从 1 位增加到多位时，宽度**必须向左单向伸展**，严禁向右或中心扩散盖住主体图标；
  - **99+ 极值收敛**：数值超过 99 时统一收敛为 `99+`，禁止显示 3 位以上纯数字；
  - **三档克制原则**：
    - 一档（待处理任务/IM消息）：展示**带数字徽标**；
    - 二档（新功能/内容更新）：展示 **6–8px 无字纯圆点**；
    - 三档（营销活动/常规系统推流）：**严禁配红点**，杜绝沦为电子牛皮癣诱发用户卸载。
- **深层页面隐藏 TabBar**：当用户进入第二级、第三级详情下钻页时，**必须隐藏底部 TabBar**，将完整的屏幕垂直视野与底部安全区让渡给当前子页面的内容或主 CTA 按钮。

### 2. 顶部切换栏 (Top Tabs) 选型判据
- **2–4 个固定分类**：使用**分段控制器 (Segmented Control)** 等分平铺，整个容器带轻量微底色和滑块切换动画。
- **5 个以上长分类**：使用**水平可横滑 TabBar (Scrollable Tabs)**，必须保证当前选中的 Tab 自动居中对齐，并在左右两端设置微弱的渐变蒙层，视觉暗示“后面还有内容可滑”。

## 二、手势交互设计体系 (Gesture Interaction Design)

手势是零界面占用的交互捷径，但**全部效率都建立在用户知道它存在的前提上**。

### 1. 手势设计的四类高频策略

| 策略类型 | 交互表现 | 典型落地场景 | 核心设计约束 |
| --- | --- | --- | --- |
| **单手操作补偿** | 双击局部放大、双击滑动缩放、长按倍速 | 地图缩放、视频全屏单手操作控制 | 必须向下兼容常规双指缩放操作 |
| **多段式手势递进** | 持续按压时长或滑动距离达到阈值后功能跃迁 | 长按点赞触发连赞/收藏；持续下拉突破阈值进入“二楼” | 达到阈值时必须触发震动触觉反馈 (Haptic Feedback) |
| **行内快捷滑块** | 列表条目向左轻扫露出一组功能按钮 | 消息列表“标为已读/删除”、邮件归档 | 滑出区域宽度控制在 70–140pt，必须带明确操作确认 |
| **沉浸式自动避让** | 页面向上滚动阅读时导航栏平滑收起 | 新闻详情长阅读、商品详情流 | 只要用户有轻微的“向下反拉”动作，导航栏必须立即重新浮出 |

### 2. 手势的不可发现性与适老底线
- **手势只能当提效捷径，严禁作为唯一功能入口**：删除、编辑、收藏等核心功能，界面中必须存在可视化的点击按钮；手势只服务于熟练用户。
- **适老模式硬规则**：在面对银发族或大字版模式时，**彻底禁用复杂多段手势与行内横扫手势**，所有操作全部还原为大号实体按钮。

## 三、橡皮筋弹性阻尼与过度滚动治理 (Rubber-Banding & Overscroll)

### 1. 弹性拖拽曲线物理公式
iOS 经典的橡皮筋阻尼效果能够给用户清晰的“拉到尽头但仍有弹性物理反馈”的高级质感。其阻尼位移位阶满足非线性渐近函数：

$$x = x_0 + \left(1 - \frac{1}{\frac{x - x_0}{d} \times c + 1}\right) \times d$$

- $d$ 为屏幕物理尺寸（通常为屏幕高度）；
- $c$ 为阻尼系数（通常取值在 0.55 左右）；
- 拖拽距离越大，手指移动时元素位移越迟缓，直至在物理极值处平滑锁止。

### 3. 滑动的肉感三大铁律 (Tactile Physics of Touch & Motion)
源自大厂动效实测（EP16）：
1. **触控 1:1 绝对零延迟跟手 (Zero-Lag Touch Tracking)**：
   - 手指贴在屏幕上移动时，位移必须是 1:1 绝对跟随，严禁在 `touchmove` 阶段施加任何 ease 缓动延迟（让人感觉界面像泡在水里迟钝）；
2. **离手初速度动量衰减 (Momentum Decay / Inertia)**：
   - 手指离开屏幕（`touchend`）的瞬间，系统根据最后 100ms 的释放初速度 $v_0$，继续向前抛掷滑动，加速度遵循指数衰减 $v(t) = v_0 \cdot e^{-kt}$，而非突然硬切静止；
3. **边界弹簧回弹肉感 (Spring Recoil)**：
   - 滑动触碰边界或抽屉展开到位时，严禁使用机械的 `linear` 或死板的 `ease-in-out`；
   - 必须采用**有质量的弹簧物理曲线 (Spring Physics)**：阻尼比 $\zeta \approx 0.75$（微弱过冲但无多余晃荡），让控件落位像真实物理材质一样具备弹性质感。

```css
/* 阻止页面弹性下拉时露出浏览器底层白色背景与下拉刷新假死 */
html, body {
  overscroll-behavior-y: contain;
  -webkit-overflow-scrolling: touch;
}

/* 列表局部横滚容器，防止横滑连带触发整页垂直晃动 */
.horizontal-scroll-container {
  overflow-x: auto;
  overflow-y: hidden;
  touch-action: pan-x;
  overscroll-behavior-x: contain;
}
```
