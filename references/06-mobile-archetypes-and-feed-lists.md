# 06 移动端核心页面原型与信息流模式 (Mobile Archetypes & Feed Lists)

移动端页面不能照搬 B 端 Web 桌面的分栏和复杂侧边栏。“一屏只做一件事，纵向流动顺畅，触底无缝加载”是移动端页面的黄金铁律。

---

## 一、移动端五大经典页面原型

```text
┌────────────────────────────────────────────────────────┐
│ 1. 信息流列表页 (Feed List)                             │
│    - 吸顶搜索栏 + 分段 Tab + 单列/双列卡片 + 触底无限加载│
├────────────────────────────────────────────────────────┤
│ 2. 沉浸式图文详情页 (Media Detail)                     │
│    - 顶部透明/动态渐变导航 + 轮播大图 + 底部固定 CTA   │
├────────────────────────────────────────────────────────┤
│ 3. 紧凑表单向导页 (Form Wizard)                        │
│    - 单屏 3-5 项输入 + 标签靠左/置顶 + 底部全宽按钮     │
├────────────────────────────────────────────────────────┤
│ 4. 个人中心与九宫格 (Profile & Grouped Cells)           │
│    - 头部资产大卡片 + 横向指标组 + 分组圆角单元格列表    │
├────────────────────────────────────────────────────────┤
│ 5. 移动端空态与异常页 (Empty & Exception)               │
│    - 简洁插画 + 说明原因 + 单一主行动出口              │
└────────────────────────────────────────────────────────┘
```

## 二、信息流列表页：下拉刷新与触底加载 (Pull-to-Refresh & Infinite Scroll)

信息流列表是移动端用户停留时间最长的场景。

### 1. 结构骨架
```text
MobileScreenLayout
├── MobileTopBar (搜索输入框 + 扫码/通知图标)
├── SegmentedTabs (高频分类标签栏，水平支持横滑)
└── FeedScrollView (可滚动主容器)
    ├── PullToRefreshIndicator (下拉加载微动画，如弹性小齿轮)
    ├── FeedCardItem* (单列图文卡片或双列瀑布流)
    └── InfiniteLoadTrigger (触底骨架屏或“正在加载更多...”)
```

### 2. 性能与虚拟列表 (Virtualization)
- **当列表超过 50 条项时**：移动端内存极易被大量 DOM 节点撑爆导致掉帧发热。必须采用虚拟滚动（Virtual List），仅渲染当前可视窗口内的 8–10 个 DOM 节点，上下节点动态回收复用。
- **图片懒加载 (Lazy Loading)**：图片进入视口前展示柔和占位底色，进入视口 150px 内再拉取真实资源，必须使用 `WebP` 格式压缩。

## 三、图片三段式裁切法则 (Image Aspect Ratio Rule)

移动端手机相册拍摄的照片长宽比五花八门（1:1、4:3、16:9、9:16 全景高图）。为了让卡片列表保持高度严谨的视觉秩序，必须执行三段式裁切规则：

| 原图高宽比 (H:W) | 判定形态 | 裁切与展示策略 | 适用场景 |
| --- | --- | --- | --- |
| **$H:W > 4/3$** | 高图 / 竖屏长图 | 裁切上下两端，保留核心中央，以 **4:3 或 3:2 竖直比例**展示 | 社区个人晒单、竖屏人像写真、海报 |
| **$3/4 \le H:W \le 4/3$** | 标准方图 | 统一按 **1:1 正方形**居中居中裁切展示 | 电商商品主图、外卖菜品列表、头像 |
| **$H:W < 3/4$** | 宽幅扁图 / 横照 | 统一按 **16:9 或 4:3 横图**居中展示 | 资讯封面图、视频播放封面、横幅 Banner |

## 四、底部常驻操作栏与主 CTA (Bottom Action Bar)

在电商购买页、打车确认页、工单审批页中，**底部主行动按钮 (CTA)** 的交互细节直接决定转化率。

### 1. 布局规范
- **高度标准**：容器高度通常为 56pt – 64pt，加上底部的 34pt 安全区，总高度约为 90pt – 98pt。
- **全宽 vs 胶囊双按钮**：
  - 单一强动作（如“立即支付”、“提交申请”）：采用 **全宽圆角主按钮**（高度 44–48pt，圆角 8–12pt 或全圆角）；
  - 双动作分流（如“加入购物车”与“立即购买”）：左右平铺，左侧采用辅助次色胶囊，右侧采用强强调品牌主色胶囊，左浅右深。

### 2. 避让与透明渐变
- 底部常驻栏背景必须采用 **高模糊毛玻璃 (Backdrop Blur 16px)** 配合半透明白底（`rgba(255, 255, 255, 0.9)`），上方加上一条 0.5px 精细微边框，确保页面内容在滚到栏后时隐约透出深度，又不影响操作识别度。
